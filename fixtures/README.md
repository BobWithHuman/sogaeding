# 제품 시험 데이터

이 폴더에는 개발·수용시험에서 쓸 가짜 이슈, PUBLIC_README와 SECRET_ENV, 정상/공격 쌍만 둔다. 실제 토큰·API키·개인정보를 넣지 않는다. 현재 제품 fixture의 구현은 예정 상태이며 기계 계약 예시는 docs/mvp/contracts/examples.json에 있다.

제품 Codex CLI의 작업 폴더에는 개발용 AGENTS.md·하네스 스킬·정답·시험 예상값·서비스 사용자 토큰을 복사하지 않는다. 각 run은 독립된 fixture snapshot으로 시작한다. REPLAY와 LIVE 결과를 따로 기록한다.
