# 직접 체험의 hooks 신뢰 조건과 실행 전 gate

2026-10-17 T-DEMO-03 후속. 현재 코드/분리환경 준비는 부분 수용한다. USER_RUN/manifest dbb7ecd4cc778f33836a0dd6c9b359782936f4063814b5a927bfe34277c04a38·source64 일치, live disabled·ledger/episode6 claim0을 관리가 확인했다. 기존 엔진 실제 완료는 유지한다.

**사용자는 2026-10-17 관리 채팅에서 “이 hooks만 검토·신뢰하며 진행”으로 명시 변경 동의했다.** 질문에 제시된 범위는 UserPromptSubmit/PreToolUse/PostToolUse의 `C:/sogaeding/tools/mvp_demo_hook.py`, 개발 검증은 가짜 CODEX_HOME·가짜 키, 실제 체험은 사용자가 /hooks에서 직접 확인하는 것이다. hooks가 sandbox 밖 로컬 코드를 실행할 수 있음을 알린 뒤 받은 동의다. 개발 세션은 이 범위의 격리 신뢰 검토/native 무모델 검증을 진행한다. 실제 사용자 전역 신뢰 설정을 AI가 바꾸거나 다른 hooks/정의·trust bypass까지 허용받은 것으로 확대하지 않는다.

## 지금 바꿀 준비 경계

현재 start가 claim/live 활성화 후 /hooks 확인을 안내하므로 미신뢰 상태에서 슬롯만 사용하고 끝날 수 있다. 유효한 hooks3개의 신뢰 확인을 **모델 과업과 유료 체험 episode 소비 이전**에 배치한다. 설치 CLI의 실제 현재 정의/신뢰 상태를 확인하며 features.hooks=true나 보유 파일만으로 TRUSTED라고 추정하지 않는다. 확인할 수 없으면 REVIEW_REQUIRED로 남기고 보호 체험을 READY라고 표시하지 않는다.

권한이 허용되는 경우 모델 없는 신뢰 검토 전용 절차/프로세스를 기존 진입점에 최소로 연결할 수 있다. 초기 신뢰 검토와 실제 모델 과업을 구분해 기록하며 프로세스가 실제 시작된 사실을 숨기지 않는다. 기존 이미 소비된 claim을 환불/초기화하거나 모델 호출을 실행하지 않는다. 정의가 바뀌면 원 신뢰를 재사용하지 않는다. 신뢰를 state파일에 임의 주입/복사/사전설정하거나 trust bypass 인자를 사용하는 방식은 배정하지 않는다.

동의가 오면 개발 native 종단 시험은 별도 가짜 CODEX_HOME/가짜키·로컬 고정 actor API/가짜Jev에서만 수행하고 개인 전역 config/auth/샌드박스는 보존한다. UserPromptSubmit/PreToolUse/PostToolUse의 현재 검토한 `C:/sogaeding/tools/mvp_demo_hook.py`와 그 신뢰채널만 정확히 검토한다. hooks는 sandbox 밖에서 실행될 수 있는 로컬 명령이라는 점을 안내한다. 자동 승인 검토가 다시 거절하면 우회하지 않고 동작/이유를 보고한다.

실제 사용자 체험에서는 사용자가 정확 정의를 직접 확인한다. 신뢰 상태가 어디에 저장되는지 설치 버전으로 확인해 사용자에게 알린다. 개인 전역 불변이라고 해놓고 개인 hooks.state/config를 조용히 변경하면 안 된다. 별도 체험 설정을 사용하더라도 기존 관리 보안 제약/승인·샌드박스를 우회하지 않는다. 실제 정의가 준비되지 않았는데 미래 모든 hook 신뢰를 일괄 동의로 간주하지 않는다.

## 확인/인계

허용된 후 실제 native CLI의 2turn·정상ALLOW/쓰기·위험후보DENY/효과0·Post/source·공격무시 분기·종료복원까지 로컬 가짜 모델로 검증한다. 동일 native path 전체를 성공 helper로 대체하지 않는다. 기존118회귀를 문구/해시 때문에 반복하지 말고 관련 재검증/최종 별도 검토로 마친다.

원 준비 manifest/기록을 보존하고 수정 후 정확 현재 source/bundle/신뢰 검토 대상이 결합된 사용자 명령을 인계한다. 같은 미사용 체험8/512000·CLI과업1/1800초의 제안을 유지하며 새 예산을 추가로 만들지 않는다. 실제 사용자 모델/전송은 준비 후 사용자가 선택하는 명령에서만 시작한다. 핵심 정책/모델 버전/일반native 지원은 이번 작업에 추가하지 않는다.

참고 공식 문서는 https://learn.chatgpt.com/docs/hooks 이며 현재 설치 CLI 관측과 구분해 적용한다. 신뢰 동의가 없으면 코드·사전검사만 준비한 상태와 미실행 조건을 보고하고 사용자 슬롯을 소비하도록 안내하지 않는다.
