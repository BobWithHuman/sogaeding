# 실제 고정 시연 성공 후

같은 두 프롬프트의 두 사실보고가 자동 ALLOW/OBSERVED·각쓰기1/PDP승인0·CONFIRM0으로 성공했다. 정상/리뷰 보고서 모두 완료·미완료 사실을 유지했다. [관리 검토](../../plans/reviews/WP-MVP-DEMO-01_20261017_frozen_actual_management.md)를 따른다.

처음 REGISTERED_MCP_ONLY는 Codex가 등록 MCP 밖 도구를 시도한 것을 막은 범위통제다. 이후 with_human MCP는 통과했다. 이번에는 actor가 공격을 무시했으므로 NO_ATTACK_ATTEMPT이며 현재 새 질문의 실제 위험후보 DENY는 미실행이다.

후속 확인에서 CLI는 exit0·616.968초로 정상 종료했고 연결 닫기·자식 정리 VERIFIED·연결0이다. 추가 종료나 재실행은 필요 없다. 아래 history는 기존 결과만 조회한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\sogaeding\scripts\mvp_demo.ps1 -Mode history -Revision frozen-demo-1
```

공유 Jev8/8·역사37/예약2368000·CLI7 claim을 사용했다. 기존 연결/start를 다시 실행하거나 새 과업을 보내지 않는다. 이번 시연의 두 정상 자동허용은 확인됐으며 일반 정확도 검증으로 확대하지 않는다.

다음 개발은 [T-DEMO-02 결과 마감](FROZEN_DEMO_CLOSEOUT_PROMPT.md)이다. 기존 이력의 읽기/파일부재/종료/줄바꿈 표시와 한 쪽 안내를 모델·actor·새CLI·새예산·서비스교체0으로 마친다. 기존 실제 파일·원장·manifest·과거 실패는 보존한다.


최신 우선순위 변경: 사용자의 DTAP 전수 비교 요청에 따라 다음 개발 준비는 [WP-DTAP-01](../WP-DTAP-01/START_PROMPT.md)이다. 기존 두 정상 시연과 종료 근거/표시 마감은 보존하며, benchmark 전수 목록·실 gateway/schema 호환·소형 actor·off/on 비교와 정확 위험후보 replay를 준비한다. 실제 유료 benchmark는 한도·manifest 준비 전 미활성이고 기존 소진 demo를 재실행하지 않는다.
