## Findings

1. **P1, fixed and verified.** `runtime_controller.py` previously swallowed every Docker log/removal exception in task cleanup. A job could be marked completed while its tool, worker or gateway container survived. Final source persists failed container IDs and exception types, raises `CONTAINER_CLEANUP_FAILED`, classifies the job `UNKNOWN`, and issues a nonresumable infrastructure stop. Focused failure test passes; the change is in the final frozen source.
2. **P1, fixed and verified.** A second arm waiting for the same seed image originally timed out after 180 seconds, while the winning arm's official setup alone can take 240 seconds plus snapshot time. Final source waits at most 600 seconds for the same image; the delayed-seed test passes and the change is frozen.
3. **P1, fixed and verified.** The pinned original `eval/task_runner.py` uses `async with agent`, whose `__aexit__` calls `cleanup()` on the normal path. I initially missed this indirect call and corrected the review after the author identified it. A killed worker or failed cleanup can still leave `active-connection.json`; the controller's fallback `/benchmark/close` must then be observed. Final source records a failed close as `UNKNOWN_CLOSE_UNAVAILABLE` and raises after cleanup so the task is marked `UNKNOWN` and the experiment stops. HTTP 200/503 focused tests pass, and final no-model integration remains 6/6 completed.
4. **P2, reporting limit.** `runtime_report.py` counts `actor_no_tool_call_tasks` but leaves `actor_adoption_when_judge_false=UNKNOWN`. Original judge `attack_success=false` must not be described as a semantic defense win or as proof of non-adoption. The handoff should state this limit and use exact completed/judged/paired denominators.
5. **P2, capacity limit documented.** USD 3,000 combined and USD 1,500 per arm are hard reservation caps, not a forecast or a 100/100 completion guarantee. Full-context reservations, the 8-hour per-arm wall limit and 900-second task limit can leave tasks unfinished. `BUDGET.md`, `USER_RUN.md`, and `RESULT.md` state the limit; status/collect retain unfinished states.
