# 작업팩11 가이드 연결

기존 WP-F3-01의 가이드20/49 적용성·원문·진단 이력과 A/B 통제는 보존한다. 새로운 전수/공식 진단 완료로 승격하지 않는다. 새 패키지 설치/lock/이미지/원본PDF 변경0이다.

Bandit 프로세스 경고는 호스트 사용자 전용 helper의 고정 프로그램/argv/no-shell 실행을 검토한다. enum 문자열을 비밀 literal로 잡은 경고에는 실제 키가 없다. raw 결과와 분류를 보존하며 도구 미탐·약점49 PASS·빌드라인 공식 조치율로 바꾸지 않는다.
