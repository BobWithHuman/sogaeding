# ADR-M01: MVP 동작 완료와 대회 제출 보강의 구분

2026-10-13 / 관리 결정. 사용자가 1인 개발로 빠르게 MVP를 만들려는 목표를 재확인했다. 기존 계획은 C/D 전체 진단·운영 보강을 MVP 완료에 묶어 범위가 과도해졌다. 이번 결정은 기능·권한 정책이나 필수 가이드의 적용 P0를 삭제하지 않고 **MVP 완료 게이트와 제출 준비 게이트를 구분**한다.

## MVP의 완료 조건

제품 핵심의 우선순위는 [09 제품 방향 정정](../09_core_product_direction.md)을 함께 적용한다. 출처 기록·권한 규칙·수동 승인만으로 원기획의 F3 자동 판정 완료를 선언하지 않는다. F3의 최소 출처 기반 자동 판정은 MVP 핵심이며, C/D 전수 제출 보강과는 별개다.

1. Docker의 현재 후보에서 등록 MCP 세 도구의 정상 읽기·정확한 댓글, DENY 실행0, CONFIRM 승인 전0/승인 후1/재사용 추가0이 동작한다.
2. A의 원자 예약·경쟁·UNKNOWN·장애/보존 보호와 B의 실제 화면·안전한 출력/승인·토큰 저장·인증 제한을 검증한다. 새 변경의 관련 회귀 및 작성자와 별도 AI 검토 근거가 있다.
3. 실제 인증 경로의 TLS/인증서 검증·역할 분리·민감정보 저장/로그 보호 등 **현재 노출 기능에 적용되는 필수 통제**의 코드·대표 실패 시험 근거를 확인한다. 기존 C/D 증거를 재사용하고 부족한 필수 항목만 좁게 보완한다. 적용 P0 결함이나 필요한 통제의 미검증이 남으면 완료를 선언하지 않는다.
4. 현재 범위의 가이드 적용 근거·20/49 초안과 초기 소스 진단·의존성 목록/audit를 연결하고 미점검·비적용 후보·한계를 명시한다. 전수 진단 완료/무약점/공식 점수를 주장하지 않는다.
5. 사용자가 로컬 URL·간단한 절차로 정상/거부/승인 흐름을 재현한다. Codex를 연결한 MVP 완료에는 현재 후보에 대한 정상 LIVE 확인 또는 변경 영향이 검토된 유효 증거가 필요하다. 공격 미시도는 차단 성공이 아니며 모델이 공격할 때까지 반복하지 않는다. 추가 유료 호출은 별도 배정 범위에서 수행한다.

B의 보고서를 받아 위 잔여를 대조한 뒤 관리 세션이 `MVP 동작 검증 완료`를 판정한다. B 완료 자체나 계획 수정만으로 현재 상태를 PASS로 올리지 않는다.

## 대회 제출 전 수행할 보강

- C의 인증서/키 교체·수명·복구 전수 조합, 더 넓은 제품 TLS negative matrix와 새 환경 재현.
- D의 설계20/약점49 항목별 전체 본문·source→sink·rule coverage·수동/동적 최종 진단, OS/이미지 SCA·공급자/라이선스 고지·SBOM 완전성, 조치·재진단과 기획서 제2항 근거.
- 고정 평가셋/성능 측정, 제출6종과 후보 버전 일치·최종 재현/검수.

사용자의 필수 PDF·대회 기준 준수 요구는 유지한다. MVP 이후에도 개발 과정에서 가이드를 적용하며 제출 전의 전수 검토를 생략하지 않는다. C/D 보강 중 현재 기능의 적용 P0 결함을 발견하면 우선 수정·재검증하고 기존 MVP 판정을 재검토한다.

## 2026-10-17 등록 MCP 엔진의 오늘 수용 기준

현재 제품 범위는 최신13/16번 계획의 등록 파일 MCP read_file/write_file이다. ADR-P04/CORE_AUTO_FINISH에서 정상 실제 Codex 과업 ALLOW→OBSERVED·제품 PDP 사람승인0과, 별도로 명시한 고정 악성 후보의 실제 gateway→실제 Jev DENY·upstream 금지쓰기0을 수용 기준으로 삼는다. 엔진 시험 client의 고정 후보를 피해 actor에 넣지 않으며 actor의 실제 인젝션 피폭/자체 저항과 구분한다. 모델 전체 정확도/전체 IPI/일반 native 보호 완료를 뜻하지 않는다.

이 좁은 엔진 수용과 변경 관련 예약/인증/TLS·무결성·실행/오류·독립 검토/원증거가 충족되면 관리가 등록 MCP 엔진 MVP 완료를 판정할 수 있다. 노출 경로의 미해결 적용 P0(R-B-002 등)는 생략하지 않는다. 전체 C/D 전수 제출보강은 계속 별도다. 실제 결과가 나오기 전 코드/준비/합성 통과만으로 완료하지 않는다.

## 지금 진행 중인 B에 미치는 영향

B 구현·브라우저 시험을 계속한다. B 결과에는 **MVP 완료에 필요한 남은 필수 항목**과 **제출 전 보강 C/D**를 나누어 보고한다. C/D 전체를 새로 시작하는 배정은 아직 없다. 기존 RESULT/REVIEW의 미완료 표현은 당시 기준으로 보존한다. 전역 T작업의 엄격한 종료 게이트는 그대로 추적하되 모든 T의 DONE을 좁은 MVP 동작 완료의 선행조건으로 삼지 않는다.
